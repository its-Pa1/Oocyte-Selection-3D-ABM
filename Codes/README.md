# Oocyte Selection Model 3D

This repository extends Simuscale for 3D oocyte-selection simulations and postprocessing.
Most project-specific code lives in `src/plugins/`, while postprocessing workflows are in notebooks under `run/notebooks_post_processing/`.

Simuscale upstream documentation: https://gitlab.inria.fr/bernard1/simuscale



## Repository Layout

- `src/`: simulation source code (including custom plugins)
- `run/`: run configurations, output folders, and postprocessing notebooks
- `run/local_run/`: local (non-MPI) run workflow and parameter files
- `run/notebooks_post_processing/`: figure/statistics notebooks
- `other_codes/`: auxiliary notebooks (GRN and initial position generation)
- `requirements.txt`: Python dependencies for postprocessing notebooks.
- `install_deps_linux.sh`: Linux dependency installer.
- `install_deps_mac.sh`: macOS dependency installer.
- `install_win.bat`: Windows dependency installer.
- `config_cmake_build.sh`: Helper script for configuring and building the project with CMake.


## Installation

### 1. C++ Dependencies

#### Linux (Ubuntu/Debian)

```bash
chmod +x install_deps_linux.sh
./install_deps_linux.sh
```

#### macOS
```bash
chmod +x install_deps_mac.sh
./install_deps_mac.sh
```
Install equivalent packages manually (cmake, gsl, opencv, png, OpenGL/freeglut).
Then build using the steps below.

#### Windows

Run the Windows dependency installer:

```bat
install_win.bat
```

Important: run the batch file from an elevated Command Prompt or PowerShell (Run as Administrator).

Then continue with the build steps below.

### 2. Build the Project

Option A: use helper script:

```bash
chmod +x config_cmake_build.sh
./config_cmake_build.sh
```

Option B: manual CMake build:

```bash
mkdir -p build
cd build
cmake ..
make 
```

### 3. Python Environment (Postprocessing)

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python -c "import statsmodels, pandas, matplotlib, seaborn, scipy; print('All packages OK')"
```

If you use VS Code/Jupyter:
1. Select interpreter `./venv/bin/python`.
2. Restart the notebook kernel after changing interpreter.


## Reproducibility

The source code and analysis notebooks provided in this repository support the reproduction of the computational
results presented in the associated manuscript.

Simulation-dependent analyses require the corresponding numerical outputs generated by the model. These include
trajectory files, quantitative measurements, and nurse-cell activation data for the different germline cyst geometries.

Postprocessing notebooks use these outputs to reproduce the figures and statistical analyses.

The simulation parameters and execution workflows are documented in the corresponding configuration files and scripts.


## Post-Processing Instructions

Before running the postprocessing notebooks, simulations must be performed for all three cyst geometries (spherical, cylindrical, and ellipsoidal).

For each geometry, place the corresponding `Quant_Files` directory and `combined_nurse_cell_activation` output file in the appropriate subdirectory under `run/Result_Files/`.

Rename each activation file to include the corresponding geometry, for example: `combined_nurse_cell_activation_sphere.txt`

## Additional Notebooks

- Initial cell positions: `other_codes/notebook_Initial_Position.ipynb`
- Local parameter sweep (no MPI): `run/local_run/notebook_local_run_without_mpi_multiple.ipynb`
- Server parameter sweep (MPI): `run/main/notebook_server_mpi.py` with `run/main/submit_job.sh` on an SLURM-based server. The current workflow is tested for sweeping four parameters: $\alpha$, $\beta$, $\zeta$, and $[P_n]_0$, configured in `run/server_run/python_params.txt`.

Local sweep parameter files:
- `run/local_run/python_params_all.txt` (multi-value sweeps)
- `run/local_run/python_params_baseline.txt` (single baseline)

Example sweep format in `python_params_all.txt` or `python_params.txt`:
- `alpha = 0.1, 0.2, 5`
